# ご紹介事業所マップ｜デザイン比較

株式会社BIG TREE向けの画面確認用試作です。GitHub Pagesでは以下の3案を同じデータと操作で比較できます。

| 案 | コンセプト | 公開予定パス |
| --- | --- | --- |
| A | やさしい配色の現行案 | `/a/` |
| B | 紺と青緑の情報設計型 | `/b/` |
| C | 生成りと深緑の読み物型 | `/c/` |

各案は「医療施設／介護施設を選ぶ → 5市から選ぶ → 施設一覧を見る」の動線を持ちます。施設のサイト画像と「公式HPを見る」ボタンは、公開されている同じURLにリンクします。

**掲載施設は厚生労働省の公開データから選んだサンプルです。BIG TREEとの連携、紹介契約、掲載承諾を示すものではありません。** 公開データのURLと施設サイトの内容は変わる場合があります。各画面には検索エンジン向けの `noindex,nofollow` を設定していますが、URLを知る人は閲覧できます。

このフォルダは配布用の静的ファイルです。編集元は別に管理しています。GitHub Pagesは `main` ブランチのリポジトリ直下から配信します。
